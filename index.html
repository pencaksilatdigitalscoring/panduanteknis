A. Alur Penggunaan Digital Scoring

  1. Menu Sekretaris

    Pendaftaran peserta secara manual dapat dilakukan pada menu sekretaris dengan mengisi kolom dan opsi tabel yang sudah tersedia, kemudian klik simpan. Apabila peserta lebih dari 1 halaman, lakukan hal yang sama dalam pengisian data yang tersedia kemudian klik simpan sebelum pindah ke halaman yang lain.

  2. Menu Looting

    Pendaftaran peserta dengan sistem looting dapat dilakukan di menu looting pada halaman input data, isikan data pada tabel yang sudah tersedia lalu klik simpan. Setelah data tersimpan masuk pada halaman data looting di menu looting, kemudian pilih filter sesuai kelas yang akan dipertandingkan dan klik tombol proses loting.

  3. Menu Operator

    Masuk pada menu operator untuk validasi data peserta sesuai dengan kategori pertandingan yang telah di daftarkan sebelumnya. Apabila data peserta sudah benar maka tahap memulai pertandingan adalah klik tombol fight di sebelah kolom peserta yang akan bertanding. Klik tombol ready apabila peserta sedang dalam partai persiapan. Klik tombol finish jika pertandingan sudah berakhir, maka tombol akan otomatis berpindah di tombol finish.

    Perhatikan dalam setiap pertandingan pastikan tombol ready, fight, finish hanya salah satu lampu yang menyala. Apabila tombol finish menyala maka tombol tidak akan bisa di ubah ke ready dan fight. Kemudian klik tombol go untuk menyalakan waktu pertandingan dan klik tombol reset untuk mengembalikan waktu pertandingan seperti semula.

  4. Menu Juri Dan Menu Dewan

    Masuk pada menu juri untuk validasi data penilaian, pastikan nama peserta dan kategori pertandingan yang di daftarkan sudah benar.

  5. Menu Jadwal

    Masuk pada menu jadwal untuk memastikan bahwa peserta yang di daftarkan sudah masuk dalam jadwal pertandingan.

  6. Menu Laporan Pertandingan

    Masuk pada menu laporan pertandingan untuk mendownlod hasil laporan pertandingan jika dibutuhkan, laporan pertandingan secara realtime maka pastikan download laporan hasil pertandingan sebelum klik tombol finish pada menu operator.

B. Fungsi Fitur Pada Menu

  1. 1. Menu Dewan

    • a. Tombol Home : kembali ke menu
    • b. Tombol Laptop : tampilan laptop
    • c. Tombol lingkaran : reset out juri
    • d. Indikator J1-J2-J3 : hijau juri in / merah juri out
    • e. Tombol Finish : pertandingan selesai dan tersimpan
    • f. Tombol Next : pertandingan berikutnya
    • g. Tombol UD : peserta undur diri
    • h. Tombol WMP : peserta menang teknik
    • i. Tombol Disk. : peserta diskualifikasi
    • j. Tombol VAR : verifikasi jatuhan dan pelanggaran
    • k. Tampilan Statistik : statistic jatuhan dan pelanggaran
    • l. Tombol (+1+2/-1-2) : pengurangan atau penambahan jika salah input
    • m. Tombol Pinalty : binaan, teguran dan peringatan
    • n. Tombol Jatuhan : poin jatuhan peserta
    • o. Tombol Anulir Jatuhan : anulir poin jatuhan

  2. 2. Menu Sekretaris

    Isi data sesuai dengan tabel kemudian klik simpan.

  3. 3. Menu Operator

    • a. Go/Pause/Reset : timer on / timer stop / reset timer
    • b. Round : perpindahan babak
    • c. Ready/Fight/Finish : partai persiapan / partai tanding / partai selesai

  4. 4. Menu Juri

    Klik tombol pukulan dan tendangan.

  5. 5. Menu Looting

    Isi data sesuai dengan tabel kemudian klik simpan.
